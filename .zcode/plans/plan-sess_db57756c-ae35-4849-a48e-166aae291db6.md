# Plan: MVVM restructure + component extraction + l10n completion (jent_web)

## 1. Findings snapshot (verified)

**Current structure (`lib/`):** flat, no `data/`, `domain/`, `models/`, `repositories/`, `services/`. Catch-all `lib/source/` holds theme + constants + shared widgets. Only 2 pages: `presentation/pages/home/` (`home_bloc/event/state/page`, 672-line `home_page.dart`) and `presentation/pages/ignition/` (`ignite_*`, 88-line `ignite_page.dart`). Shared UI lives in `lib/source/animation/` (`AdaptiveMenuBar`, `PremiumAnimatedBackground`, `WaterFillLogo`) and `lib/source/widget/dock/` (`DockWidget`, `DockIconWidget`). No `presentation/widgets/`, `components/`, or per-page `widgets/` folder. l10n is wired (`l10n.yaml`, `lib/l10n/app_id.arb` template + `app_en.arb`, 16 keys, `AppLocalizations.delegate` in `lib/app.dart`) but incomplete.

**MVVM violations confirmed:**
- No data layer: zero `*repository/*service/*datasource/*usecase` files; `HomeBloc._onSendEmail` (`lib/presentation/pages/home/home_bloc.dart:101-103`) is an empty stub, so email I/O is untestable.
- Logic in View: `home_page.dart` owns window drag/size math (`_MailOverlayState._computeWindowSize/_initPosition/_onDragDelta/_clampPositionToBounds`), form state + 4x `TextEditingController` + `_canSend` + `_handleSend` with `Future.delayed(700ms)` close (`_MailWindowState`), and `MediaQuery.sizeOf` sizing duplicated (lines ~207-215 vs ~407-408).
- Bloc mirrors state in private fields (`_showWindow/_isExpandedWindow/_isMinimizedWindow`, `home_bloc.dart:9-11`) with guard-clause early returns; expand toggle reads the private var, not `state`.
- `HomePage extends BasePage` but `State<HomePage>` does NOT extend `BasePageState` (unlike `IgnitePage`), so `showLoading/showBaseBottomSheet` in `lib/presentation/base/base_page.dart` are dead code for Home.
- Scoped `BlocProvider(create: HomeBloc()..add(...))` inside `build()` (`home_page.dart:49-50`, same pattern in `ignite_page.dart:30`); no app-level DI / `RepositoryProvider`. Concrete `HomeBloc` passed as widget ctor param (`_MailWindow(bloc: context.read<HomeBloc>())`) instead of reading inside.
- Naming drift: `source/` catch-all, `colors.dart` at root vs `constants/` subdir, `ignition/` folder vs `ignite_*` files, over-nested `source/widget/dock/`, stray root `marquee.dart` (22KB), `locale: Locale('id')` hardcoded in `lib/app.dart:17` making `en` unreachable.

## 4. MVVM execution phases (move-only first, logic moves second)

- **P0 baseline:** `flutter analyze`, `flutter test`, record; decide template ARB stays `app_id.arb` or switch to `en`.
- **P1 folder moves (no logic change):** `source/` → `core/` per §2 map; fix imports; rename `ignition/`→`ignite/` OR files→`ignition_*` (pick one); move `_FormRow`/window widgets to new homes; delete or wire in stray `marquee.dart`; decide whether checked-in `lib/l10n/*.dart` generated files stay or become build-only.
- **P2 ViewModel cleanup:** remove private `_showWindow/_isExpandedWindow/_isMinimizedWindow` mirrors, derive from `state`; move drag-bounds/size math, `_canSend` validation, and send-then-close delay from widgets into `HomeBloc` events/state; replace cached `_localizations`-as-ctor-arg (didChangeDependencies → passed to `_Dock/_MailOverlay/_MailWindow/_FormRow`) with `AppLocalizations.of(context)` at use site; make `State<HomePage>` extend `BasePageState` or drop `BasePage` inheritance.
- **P3 Data layer:** add `domain/entities/email_message.dart`, `domain/repositories/email_repository.dart`, `data/...` impl using `mailer`; implement `_onSendEmail` via repo; emit sending/sent/error states instead of widget-local `_sent` flag.
- **P4 DI + routing:** add `get_it` (or `RepositoryProvider`/`MultiBlocProvider` at app level); provide `EmailRepository` + `HomeBloc`/`IgniteBloc` above `MaterialApp.router`; remove per-build `BlocProvider(create:)`; stop passing concrete Bloc through widget ctors.
- **P5 Tests:** add `bloc_test` + `mocktail` (dev_deps); bloc tests for wallpaper rotation/window toggles/send-email states; widget test for extracted `MailWindow` validation; replace default `test/widget_test.dart` counter test.
